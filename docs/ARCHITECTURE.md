# 架构说明

LocalKey 是 .NET Framework 4.8 / C# / WinForms 桌面程序。没有服务器或浏览器扩展，常规运行不创建联网客户端。

## 模块

| 文件 | 职责 |
| --- | --- |
| `src/Program.cs` | STA 入口、按 Windows 用户 SID 命名的当前会话单实例互斥、数据路径和测试参数路由 |
| `src/UI.cs` | 主窗口、账号编辑、查询、托盘、快捷键与定点倒计时控制 |
| `src/Vault.cs` | 记录模型、JSON 序列化、DPAPI 加解密、文件校验与原子保存 |
| `src/Native.cs` | user32 调用、全局快捷键、UI Automation 目标捕获和 Unicode 输入 |
| `src/CountdownForm.cs` | 不主动取得焦点的倒计时提示 |
| `src/ClipboardLease.cs` | 主动复制及按剪贴板序列号执行的到期清理 |
| `tests/` | 独立临时密码库、替身剪贴板和受控桌面 / Edge 测试驱动 |

当前编译方式把测试驱动一并编入 EXE。它们位于显式命令行测试参数之后；不带参数的普通启动不执行测试。核心测试不打开真实密码库，也不写真实剪贴板。

## 数据格式

文件按以下顺序存储：

1. 8 字节 ASCII 格式标记 `LKDP0001`。
2. 4 字节 little-endian 密文长度。
3. Windows DPAPI 保护后的字节。

密文对应 JSON 文档，包含版本号与记录列表。记录包含 ID、名称、账号、密码、网站 / 应用和备注，整体位于加密载荷中。文件头不是密文，可能暴露格式、长度和文件存在性。

加密调用 `ProtectedData.Protect` / `Unprotect`，范围为 `DataProtectionScope.CurrentUser`。代码中的固定 entropy 字符串仅作为应用命名空间，不是秘密密钥。Windows 提供并保护用户密钥，项目不自行选定或保存某种 AES 密钥。

读取限制最大文件约 8 MiB、最多 10,000 条记录，并校验结构和字段长度。保存先写临时密文并刷新，再用 `File.Replace` 替换并产生 `.bak`；首次保存使用文件移动。它不提供跨会话或多进程并发编辑冲突解决。

## 填写流程

自动模式捕获唤起前的窗口、进程和焦点身份；隐藏主窗口后切回目标，再逐个 Unicode 字符输入。每次输入前检查前台、焦点和按键状态。账号连填只发送一次 Tab，等待焦点更新后要求密码标记，不扫描整页寻找任意密码框。

定点模式由用户明确开启，要求在倒计时中重新点击，点击释放后捕获焦点。它仍检查可编辑性、窗口、焦点和按键，只对选定单个字段输入，不要求密码标记，也不发送 Tab。

检查与系统输入不是原子事务，其他窗口或页面可能在期间变化，因此中止时可能留下部分内容。未实现域名绑定、表单语义识别或提交功能。

## 缓存与剪贴板

闲置、主动收起或 Windows 锁屏后清空账号列表引用；托管字符串的原内存不保证完全擦除。

剪贴板只在用户选择复制时写入。写入后记录序列号，到期或主动清理时仅在序列号未变化时清除。写入请求 Windows 排除历史与云同步；无法限制其他进程读取，也不保证崩溃后的清理。
