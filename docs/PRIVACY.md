# 数据、隐私与恢复

## 保存什么

名称、账号、密码、网站 / 应用、备注及记录 ID 都保存在加密载荷中。默认文件：

- `%LOCALAPPDATA%\LocalKey\vault.lkey`：当前密码库。
- `%LOCALAPPDATA%\LocalKey\vault.lkey.bak`：上一次保存的加密备份。

文件头含格式标记和密文长度；文件系统仍可看到文件大小、时间等元数据。应用不采集遥测，没有云同步、账号注册或联网客户端。测试模式启动的 Edge 是独立测试程序，浏览器自身的网络行为不属于 LocalKey 的联网实现。

## 加密与访问边界

LocalKey 使用 Windows DPAPI `CurrentUser`，不以明文保存账号记录，也不自行保存加密密钥。解密依赖 Windows 用户身份及其密钥；没有额外主密码、恢复口令或远程恢复服务。

可以操作当前已登录会话的人可以打开软件。同一 Windows 用户下的恶意程序，以及具备足够权限的攻击者，不在本工具的隔离保证内。加密库文件并不能替代 Windows 会话保护。

运行时需要解密账号以显示和填写。尽管退出或清理时会释放引用，.NET 字符串不能保证在进程内存中彻底擦除。崩溃转储、内存抓取或敏感截图也可能包含数据，不要公开上传。

## 剪贴板

自动与定点填写通过 Unicode 输入，不使用剪贴板。点击复制按钮才会写入剪贴板，并请求 Windows 不加入历史或云同步。

20 秒后程序尝试清除本次仍拥有的内容；后复制的其他内容通过序列号区分并保留。清理依赖程序继续运行和剪贴板可用。系统或其他软件仍可能读取、缓存或同步内容；不要将清理理解成防读取或安全擦除。

## 备份与删除

`.bak` 保留上一次保存，可能含已删除的账号。删除记录不等于清除所有历史磁盘内容。移动、卸载或删除 EXE 不会删除密码库。项目不提供安全擦除工具。

在原 Windows 用户仍能解密的情况下，恢复上一次备份：

1. 从托盘完全退出 LocalKey。
2. 把现有主文件与 `.bak` 复制到其他位置留存，不覆盖唯一副本。
3. 将 `.bak` 复制为原目录里的 `vault.lkey`。
4. 用原 Windows 用户打开并核对记录。

复制加密文件不能单独完成跨电脑或重装迁移。换 Windows 用户、重装系统、丢失用户密钥或某些账户重置操作后，可能无法解密；具体可恢复性取决于 Windows 密钥与账户配置。当前没有可移植导出格式，请在变更系统前另行确保自己能恢复所需账号。

## 问题反馈

公开反馈使用虚构账号和离线简化表单，不附上密码库、备份、真实截图、内部地址、Cookie 或令牌。安全漏洞按 [安全政策](../SECURITY.md) 报告。
